Sixty

Privacy policy

Effective 23 October 2026. Sixty collects no personal data.

What Sixty reads

Every 2 seconds Sixty reads which apps use the microphone, the speaker and the camera, so that it never locks the screen during a call. It reads only the "device in use" flags that macOS publishes. It never records, reads or stores audio or video. It also reads how long ago you last used the keyboard or the mouse, to count your work time.

What Sixty stores

On your Mac only, in its preferences file: the current work counter, today's number of breaks and emergency exits, and (GitHub edition) the time of the next update check. Nothing leaves your Mac.

Network

The Mac App Store edition makes no network requests at all. The GitHub edition makes one kind of request: twice a day it asks api.github.com for the latest release of Sixty and, if there is one, downloads it from GitHub. The request carries no data about you; GitHub sees your IP address, as with any visit (see GitHub's privacy statement).

No accounts, no analytics, no third parties

Sixty has no accounts, no analytics, no advertising and no crash reporting. It shares nothing with anyone. This website loads nothing from third parties either.

Contact

Sixty is open source; the code that does all of the above is at github.com/leplik/sixty. Questions: open an issue. Publisher: SAAC sp. z o.o. Developer: Aliaksei Smirnou.
